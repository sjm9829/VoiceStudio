# 02. UX 명세

## 1) 메인 `나레이션` 화면
- 상단: 목소리 드롭다운 + `목소리 관리` 버튼
- 중앙: 큰 `대본` 입력창, placeholder `음성으로 만들 대본을 입력하세요.`
- 주요 버튼: `음성 생성`
- 생성 상태 표시(쉬운 한글): `모델을 준비하는 중…` → `구간 n/m 만드는 중…` → `MP3를 만드는 중…` → `완료`
- 완료 후: 내장 재생 컨트롤 + `MP3 저장`
- 생성 중 `취소` 가능. UI 스레드 점유 금지.
- 프로필이 없으면 `목소리를 먼저 등록해 주세요.` 안내 + 목소리 등록 바로가기.

## 2) `목소리 관리`
- 카드/목록: 이름, 등록일, 참조 길이. `편집`, `삭제`, `+ 목소리 등록`.
- 삭제는 확인 대화상자.
- 표시 이름 중복은 막고 안내합니다.

## 3) `목소리 등록/편집`
- 이름 입력
- 참조 파일 선택: MP3/M4A/WAV/FLAC
- 전체 음원 파형 + 시작/끝 드래그 핸들 + 선택 구간 시간 표시 + 선택 구간 들어보기
- 길이 정책: 3초 강제 없음. 15초 안내 문구는 `사용 가능하지만 더 길다고 반드시 좋아지지는 않습니다`.
  지나치게 긴 선택은 경고만 하고 임의 절단하지 않습니다.
- `참조 음성의 대사` 입력창 + `자동 받아쓰기` 버튼(선택 구간만, CPU). 결과는 사용자가 수정 가능.
- ICL 등록에서는 대사가 비어 있으면 등록 불가.
- 등록 동의 체크박스: `이 음성을 사용할 권한이 있음을 확인합니다.` 체크 전 등록 금지.
- 등록 시 별도 프로세스에서 음성 분석을 수행하고 완료 후 종료합니다.

## 4) `설정`
- 기본 MP3 저장 폴더: `%USERPROFILE%\Music\보이스 스튜디오`
- MP3 음질: 표준 128 / 고음질 192(기본) / 최고 256 kbps, Mono
- `NVIDIA 그래픽 카드 사용` 상태/장치 표시, CUDA 불가 시 명확한 오류와 진단 정보
- `사용 후 그래픽 메모리 해제`: 기본 ON, v1 고정 동작(작업 프로세스 종료). 고급 설정에 설명만 제공
- 음성 모델 상태/버전/저장 경로, `모델 받기`, `모델 다시 받기`
- 자동 받아쓰기 모델 상태/받기/삭제

## 오류 메시지 원칙
- 사용자 행동 + 다음 행동 중심의 한글 문장. 내부 스택트레이스는 로그에만 기록.
- 예: `오디오 처리 프로그램(FFmpeg)을 찾을 수 없습니다. 설치 후 다시 시도해 주세요.`
