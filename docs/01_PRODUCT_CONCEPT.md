# 01. 제품 개념

## 제품명과 한 줄 정의
- 제품명: 보이스 스튜디오
- 설명: `등록한 목소리로 자연스러운 나레이션을 만들어 주는 음성 생성 프로그램`

## 대상 사용자
- Windows 일반 사용자. 개발자 도구, 웹서버, Docker에 대한 이해가 없어도 사용 가능.

## 핵심 가치
1. **로컬 우선**: 음성·대본·프로필은 외부 서버로 업로드되지 않습니다.
2. **단순 UI**: 메인 화면은 목소리 선택 → 대본 입력 → 생성 → 저장 4단계만 노출합니다.
3. **언제든 목소리 추가**: 최초 실행 전용 등록이 아니라 언제든 목소리를 추가/편집/삭제합니다.

## 화면 구성 (초보자 기준)
| 화면 | 목적 |
|---|---|
| 나레이션(메인) | 목소리 선택, 대본 입력, 생성, 미리듣기, MP3 저장 |
| 목소리 관리 | 목소리 목록, 추가/편집/삭제 |
| 목소리 등록/편집 | 참조 파일 선택, 구간 선택, 대사 입력, 자동 받아쓰기 |
| 설정 | 저장 폴더, 음질, 그래픽 카드 상태, 모델 관리 |

## 용어 정책
- 사용자 화면은 최대한 한글. MP3/GPU/NVIDIA 등 통용 기술어만 영문 허용.
- TTS/STT/embedding/inference/worker 등 내부 용어는 UI에 노출하지 않습니다.
- 특정 개인/가족을 지칭하는 문구는 UI·문서·코드 어디에도 넣지 않습니다.

## 범위 밖 (v1)
클라우드 계정, 웹서버, 다중 사용자, 영상 편집기, Voice Design, 실시간 대화, 스트리밍 서버.

## 산출물
- 최종 사용자 산출물은 MP3 하나. 내부 임시/프로필 데이터만 PCM/FLAC/safetensors 사용.
